## 沿用的交互规则

以下规则都来自参考看板在真实使用中踩过、修过的问题：

1. **全局筛选条跨页共享**：日期、媒体、产品、代理、账户、运营在各看盘页之间保持；搜索与刷新都点按钮才触发，避免输入过程反复查询。
2. **派生指标重算**：合计行与分组行的 ROI、CPC 等由汇总后的基础指标重算，不平均明细比值；分母为 0 留空。
3. **表格按原始值排序**：金额、百分比按数值排序，不按格式化后的字符串排序；支持冻结首列、列设置和密度切换。
4. **导出与页面同范围**：CSV 导出复用页面的查询与数据范围，导出结果与屏幕所见一致。
5. **账号级偏好**：主题与列设置按账号保存，换设备保持一致；并发修改用版本号检测冲突。
6. **导航按角色裁剪**：代理类账号只看聚合与分天明细，看不到真实收益口径；真实口径与对外口径权限不能同时授予同一账号。
7. **主题系统**：浅色、深色、跟随系统；12 套预设加自定义主色（HEX / RGB / HSL）；浅色追求干净清晰，不压灰、不给内容卡片加模糊；各主题文字对比度满足 WCAG AA。
8. **导入幂等**：按文件覆盖的日期整天替换，重复导入不会累加。

## 不迁移

参考看板中与特定公司、特定媒体账号绑定的功能不进入本项目：媒体官方 API 授权、官方 API 观察、特定媒体收益参考、联盟数据采集、飞书推送。

## 数据边界

- 只使用固定种子生成的虚构数据；产品、代理、账户、运营名称均为虚构。
- 本机演示包含管理与只读角色，供维护者验证写操作；目前没有公网演示部署。
- 后续公开演示只开放只读业务账号，不能写映射、导入或账号。公开部署前禁用管理账号并按 [发布清单](release-checklist.md) 验证服务端权限。
