# 服务端权限矩阵

界面隐藏菜单和列只是体验。验收标准是：**代理直接调接口、改账户 ID、触发导出、跑后台任务，都拿不到越权数据。**

本文件同时记录目标设计与已实现约束。v1 已实现认证、报表/导出、账号管理、账户归属映射、导入和审计；推广配置、回传、采集、媒体凭据、财务及事件消费仍是后续设计，不代表当前已有这些接口。当前页面范围见 [演示指南](../demo-guide.md)。

## 四层

1. **操作权限**：能否调用这个接口（权限码）。
2. **数据范围**：能看到哪些代理 / 产品 / 运营 / 账户的数据（行级）。
3. **字段可见性**：对外口径账号看不到收益类字段（列级）。
4. **租户隔离**：跨租户永不可见，且与前三层独立。

## 数据范围规则

- v1 授权维度为代理、产品、运营；媒体账户通过这些归属维度受限，尚无独立的账户授权数组。三个授权维度之间取交集。
- 某维度省略或为 `null` 表示该维度不限；非空数组表示只授权列出的值；显式 `[]` 表示没有授权值。因此任一授权维度为 `[]`，事实查询、筛选可选值和导出都不能返回事实数据。
- 报表和导出的范围判定在 SQL 中完成，与用户筛选取交集，**不能靠应用层过滤报表结果**。请求筛选中的 `[]` 只表示不额外筛选，不能与授权范围的 `[]` 混为一谈。
- 未映射数据（没有代理 / 产品 / 运营归属）只对不限范围的账号可见。
- 导出、后台任务、定时报告与在线查询共用同一套范围判定代码路径。

### 账号管理的目标可见性

Java `UserAdminService` 在同租户条件下检查目标账号的代理、产品、运营三个维度，全部满足才可出现在列表或被修改：

- 操作者在某维度为 `null`/省略，该维度不限制其管理目标。
- 操作者在某维度受限，目标账号在该维度必须有**明确、非空**的授权值，且全部包含在操作者范围内。目标缺少该键或为 `null` 表示不限，不能被受限管理者接管；目标为 `[]` 也不满足“明确归属”，由上级管理员处理。
- 操作者某维度为 `[]` 时，没有可管理的目标账号；这不能被解释为不限。
- 创建或修改授出的角色权限必须是操作者权限的子集，三个授出维度同样不能比操作者宽。允许把授出范围缩小到 `[]`；缩小后该账号的事实数据为空，后续恢复由有权的上级管理员处理。

账号归属可见性与事实范围筛选是两个判定：不能因为空集合在数学上属于任意集合，就允许受限管理员管理没有明确归属的账号。

## 字段可见性

对外口径隐藏：收益、ROI、点击 ARPU、回收差额、毛利、变现相关列。默认列自动剔除；显式请求这些字段返回 403，不返回空值——返回空值会让调用方以为数据为零。

## 强制点

| 位置 | 要求 |
|---|---|
| 在线接口 | 每个接口独立鉴权 + 范围过滤，不依赖前端传来的租户或范围 |
| 导出 | 与页面同一查询路径，同一范围判定；导出产物带生成者与范围快照 |
| 后台任务 | 任务持久化时记录发起人与范围，执行时重新校验，不信任入队时的判定 |
| 事件消费 | 消费者重新解析主体与范围，不从消息体里取权限结论 |

## 越权测试清单（必须自动化）

1. 代理账号调用趋势 / 原始明细接口 → 403。
2. 代理账号在请求体里塞其他代理的 ID → 返回空集，且不报出该 ID 是否存在。
3. 代理账号请求收益类指标 → 403；默认列不含收益类字段。
4. 跨租户的账户 ID、推广 ID、导出任务 ID → 404（不是 403，避免探测存在性）。
5. 运营账号对范围外推广执行批量改规则 / 批量回传 → 403，且无任何写入。
6. 过期或被吊销令牌 → 401；停用账号即时失效。
7. 任务队列中伪造的租户字段 → 消费端重新校验后拒绝执行。
