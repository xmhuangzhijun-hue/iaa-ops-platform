# 作品集 v1 演示指南

候选版本：`v1.0.0-rc.1`。这是开源 MVP 的本机演示指南，尚无公网演示部署。先按 [README](../README.md) 启动 Java 和前端，打开 [http://127.0.0.1:5173](http://127.0.0.1:5173)。实际验收记录以 [STATUS](STATUS.md) 为准，下面是可复现的演示步骤和预期行为。

## 五分钟主线

1. 用 `demo.admin` / `iaa-demo-2026` 登录。导航只展示已接入真实服务的看盘和管理页面。
2. 进入“聚合看盘”，选择最近 7 天，点“查询”。查看消耗、收益、ROI，并按产品或账户分组；分组与合计共用指标口径，ROI 按总收益 / 总消耗计算。
3. 保留筛选进入“趋势图”和“ROI 异常清单”。调整日期或阈值后重新查询；空结果也是有效结果，不应出现虚构填充的数据。
4. 进入“原始明细”，按实际种子日期查询，导出 CSV，核对所选日期、筛选和指标。种子默认截至昨天，今日为空属于正常情况。
5. 查看“账户分配”中媒体、账户、代理、产品、运营的归属关系，再到“指标与字段说明”核对 ROI 等字段的定义。

所有统计数值随选定日期和种子结束日变化；演示不以某个固定 KPI 数字作为成功条件。确认查询完成、分组与合计一致、图表和表格使用同一筛选才是关键。

## 角色隔离

通过页面退出登录，再切换账号。以下账号只对应虚构数据，口令均为 `iaa-demo-2026`。

| 账号 | 要看到的差异 |
|---|---|
| `demo.admin` / `demo.company` | 可管理账号、分配账户、导入、查看审计；能看真实收益指标 |
| `demo.operator` | 只见“运营甲”范围；可看真实收益指标，无系统管理写权限 |
| `demo.agency` | 只见“星河代理”范围；不显示变现收益、ROI 等真实收益字段；只管理本代理账号 |
| `demo.readonly` | 可查询聚合与分天数据；无业务管理写权限，无真实收益指标 |

前端菜单隐藏只是界面提示，实际范围由 Java 查询和写接口强制。授权范围省略或 `null` 表示该维度不限；显式 `[]` 表示该维度没有授权值，事实查询与导出为空。它与报表筛选的空数组不同：筛选为空只是不再缩小已授权范围。

F-01 的回归结果记录在 [facts 审计](design/facts-module-split.md) 和本轮验收记录中。不要为了演示把管理员当前账号改成无法访问的角色；若要体验创建账号和临时口令，使用单独的虚构账号。

## 导入演示

使用 `demo.admin`，进入“数据导入”，媒体选择 vivo。下载 [演示样表](examples/v1-demo-import.xlsx)，日期为 **2020-01-01 和 2020-01-02**，避开默认最近 60 天的种子数据。先核对当前数据库这两天没有需要保留的 vivo 数据，因为导入会替换该媒体这些日期的全部数据。

样表只有一个工作表，也可在 Excel/LibreOffice 按下表重建 `.xlsx`。第一行为列名，日期用文本或日期单元格保存，不要使用公式。

| 日期 | 小时 | 账户 | 推广计划 | 消耗 | 预估收益 | 曝光 | 点击 |
|---|---:|---|---|---:|---:|---:|---:|
| 2020-01-01 | 10 | vivo-demo-001 | plan-demo-1 | 100 | 150 | 10000 | 1000 |
| 2020-01-01 | 11 | vivo-demo-001 | plan-demo-2 | 300 | 150 | 20000 | 2000 |
| 2020-01-02 | 10 | vivo-demo-001 | plan-demo-3 | 200 | 260 | 40000 | 4000 |
| 2020-01-02 | 99 | vivo-demo-001 | plan-invalid | 999 | 999 | 1 | 1 |

1. 上传，页面受理后显示任务状态，再变为“已完成”。很小的文件可能直接看到终态。
2. 检查覆盖日期为上述两天，写入 3 行；首次无旧数据时替换 0 行。第 5 行“小时”超出 0–23，提示 1 行没有导入。
3. 在看盘页筛选这两天和 vivo，消耗合计应为 **600**、收益 **560**，ROI 由 `560 / 600` 得出；原始明细只有 3 行。
4. 重复上传同一文件，应仍写入 3 行、替换 3 行。再次查询合计仍为 600/560，不会翻倍。
5. 打开“审计日志”，查看本次导入的写操作记录。

这是可预期的成功加坏行场景；任务完成并不等于所有行都导入。若需要恢复全新演示状态，只对专用演示库重跑种子，并理解其会重建该租户核心数据；不要对共享数据库随意清库。

## 页面与展示边界

| 分组 | 页面 | 路由 |
|---|---|---|
| 看盘分析 | 聚合看盘 | `/analysis/aggregate` |
| 看盘分析 | 分天明细 | `/analysis/daily` |
| 看盘分析 | 趋势图 | `/analysis/trend` |
| 看盘分析 | ROI 异常清单 | `/analysis/roi-anomalies` |
| 看盘分析 | 原始明细 | `/analysis/raw` |
| 系统管理 | 用户与权限 | `/system/users` |
| 系统管理 | 账户分配 | `/system/assignments` |
| 系统管理 | 数据导入 | `/system/imports` |
| 系统管理 | 指标与字段说明 | `/system/metrics` |
| 系统管理 | 审计日志 | `/system/audit` |

登录和改密另有独立页面。各账号只显示有权限的菜单；首页进入该账号首个可访问页面。

产品与品类、媒体账户、数据源采集、字段映射、推广计划仍是早期原型；报告、策略、财务等尚无完整实现。旧 mock/占位路由不再注册，直接访问会提示页面不存在或没有权限，可返回首页。原型源码保留供后续设计参考，演示入口不启用 mock 拦截。

媒体 API 自动采集、归因、回传、结算、分布式任务可靠性和公网容量均不是本次交付承诺。公开部署需要另行关闭管理账号与写入口、配置真实密钥及入口防护。当前账号/IP 失败锁定仅适用于单实例，重启会重置；默认反向代理会使多个访问者共用一个 IP 额度。详见 [发布清单](release-checklist.md)。
