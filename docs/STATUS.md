## Agent 工作台

- 产品转为「运营 IDE」：原始数据 / 计划配置 / 回执为主区，Agent 为右侧助手；默认导航收敛，原报表路由保留用于复核。
- 新增 7 个 Java API，共 31 个；单模型工具循环复用授权报表和指标目录。用户 / 模型不能传身份提权，没有任意 SQL、任意 URL 或直接执行预算的工具。
- Flyway V3 管理沙箱计划、运行、提案与回执。具体预算 / 出价变更必须由人确认；授权、到期、版本、幂等及配置 / 回执事务在服务端执行。
- 运行历史和来源属于本人。权限或映射变化后拒绝旧结果；审批等待期间撤权、执行中撤权的两种并发顺序已有回归验证。审计保存索引和数量，敏感差异只在受授权保护的回执中。
- 全部事实和计划虚构；真实 DeepSeek 调用已验证查询、待确认提案、批准写入、重复回执和只读拒绝。分析正文仍有比较 / 归因错误，不能宣称语义验收全部通过。
- 文档入口：[设计](agent/design.md)、[需求](agent/requirements.md)、[演示与配置](agent/demo.md)、[开源参考](agent/references.md)、[本轮验收](../reports/agent-acceptance.md)。

本地后端全量 143 项、Python 48 项、前端类型与构建通过。浏览器已验证查询 / 来源 / 批准 / 拒绝 / 回执 / 只读身份隔离和窄屏。源码 `3d8313c` 的 [公开 CI](https://github.com/xmhuangzhijun-hue/iaa-ops-platform/actions/runs/35258094651) 四项全部通过，下载核对双后端对照 57 / 0 / 0 / 17；详见本轮验收报告，下面 RC1 数字只描述既有基线。

Agent 限制：单任务而非持续多轮会话、单实例后台运行器、重启标失败而非恢复、无主动取消、无模型费用限额、无真实媒体执行。当前来源是授权查询快照，尚无文件到事实行的完整血缘。开源作品不等于生产上线或真实客户案例。

## 权限与契约

- F-01 空授权范围越权已修复：省略/null 不限、[] 无可见事实、非空授权与请求筛选取交集。普通请求空筛选语义不变。
- 邻近账号管理问题同步修复：目标可见性同时检查代理、产品、运营范围；把拟授予范围收窄也不能接管范围外账号。受限管理者不管理不限或空归属目标；由上级管理员处理。
- 修改前复现与永久防回归见 [F-01 记录](../reports/f01-permission-regression.md)。facts 暂不拆，等待第三调用方或归因业务，见 [审计](design/facts-module-split.md)。
- 登录失败保护按账号/IP 双维计数，默认 5/20 次、15 分钟窗口与锁期；统一 401 INVALID_CREDENTIALS，事务提交后清零。边界见 ADR-0004。
- 契约暂由 Python 模型加显式 Java 操作登记导出；`x-implementation` 表示 Java，`x-reference-implementation` 保留 Python 8 个 planned/501 的真实状态。不是已迁移到 springdoc。

## 已知限制

- 登录保护是有界单机内存：重启清零、多实例不共享；默认不信任转发头。经代理会共用代理 IP 额度，公网需入口限流与可信代理配置。
- 导入采用进程内异步任务，没有进程中断后的持久恢复；按媒体/日期整体替换，文件没有列出的同日账户也会被替换。页面明确显示覆盖日期。
- 受限管理员的用户列表在数据库分页后过滤，total 是本页可见数量；大量账号时分页完整性仍有限制。权限拒绝是服务端强制，不因此放宽。
- 前端暂无自动化浏览器端到端套件；本轮记录实际人工式浏览器操作。
- FastAPI 仍可作迁移对照，8 个管理操作未实现；对外仅暴露 Java。两侧请求校验顺序仍可能有差异。
