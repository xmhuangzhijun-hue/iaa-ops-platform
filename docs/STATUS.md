- F-01 空授权范围越权已修复：省略/null 不限、[] 无可见事实、非空授权与请求筛选取交集。普通请求空筛选语义不变。

## 已知限制

- 登录保护是有界单机内存：重启清零、多实例不共享；默认不信任转发头。经代理会共用代理 IP 额度，公网需入口限流与可信代理配置。
- 导入采用进程内异步任务，没有进程中断后的持久恢复；按媒体/日期整体替换，文件没有列出的同日账户也会被替换。页面明确显示覆盖日期。
- 受限管理员的用户列表在数据库分页后过滤，total 是本页可见数量；大量账号时分页完整性仍有限制。权限拒绝是服务端强制，不因此放宽。
- 前端暂无自动化浏览器端到端套件；本轮记录实际人工式浏览器操作。
- FastAPI 仍可作迁移对照，8 个管理操作未实现；对外仅暴露 Java。两侧请求校验顺序仍可能有差异。
